# Security Policy

## Supported Versions

Currently, only the latest version of UnifiedDraw is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| > 1.0.x | :white_check_mark: |
| < 1.0.x | :x:                |

## Reporting a Vulnerability

We take the security of UnifiedDraw seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately via the GitHub Security Advisory feature or by emailing the repository owner directly.

You should receive a response within 48 hours. If the issue is confirmed as a vulnerability, we will open a private draft security advisory, patch the vulnerability, and publish the advisory.
